# Product Context

## Purpose
Fishing World mang lại trải nghiệm game câu cá 2D thư giãn nhưng hấp dẫn trên trình duyệt web, không cần cài đặt phức tạp, chạy mượt mà trên cả máy tính và điện thoại thông minh.

## User Experience Goals
- **Điều khiển linh hoạt**: Hỗ trợ bàn phím (WASD, E, F, P, Q, I, Space) trên Desktop và Virtual D-pad / Touch Action Buttons trên Mobile.
- **Giao diện trực quan**: Các cửa sổ UI (Túi đồ, Cửa hàng, Sổ tay cá, Nhiệm vụ) độc lập, dễ thao tác và phản hồi tức thì.
- **Phản hồi hình ảnh & âm thanh**: Hiệu ứng thời tiết, chiếu sáng Ngày/Đêm sống động, hiệu ứng cá nhảy, âm thanh tương tác cắn câu và hoàn thành nhiệm vụ.
- **Tiến trình chơi rõ ràng**: Hệ thống cấp độ (XP), mở khóa trang bị mới, làm nhiệm vụ và sưu tầm trọn bộ Fishpedia.
