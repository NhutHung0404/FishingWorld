# FISHING WORLD - MEMORY BANK RULES

Bạn đang làm việc trên dự án Fishing World.

## 1. Khi bắt đầu Task
- Đọc memory-bank/projectBrief.md.
- Đọc memory-bank/activeContext.md.
- Đọc memory-bank/progress.md.
- Chỉ đọc các file Memory Bank khác khi cần thiết.
- Kiểm tra mã nguồn thực tế trước khi chỉnh sửa.
- Không đọc toàn bộ dự án nếu không cần thiết.

## 2. Quy tắc code
- Sử dụng JavaScript ES Modules.
- Duy trì kiến trúc OOP.
- Ưu tiên Single Responsibility Principle.
- Không viết lại module đang hoạt động nếu không cần thiết.
- Không xóa tính năng cũ.
- Không thay đổi gameplay ngoài phạm vi yêu cầu.
- Không tạo file trùng chức năng.
- Giữ tương thích Desktop và Mobile.
- Bảo toàn TouchControls, Responsive, Canvas DPR và Renderer.

## 3. Phạm vi công việc
- Làm việc theo từng Phase và Step.
- Chỉ thực hiện Step được giao.
- Không tự động chuyển sang Step tiếp theo.
- Nếu phát hiện vấn đề ngoài phạm vi, báo cáo trước khi sửa.

## 4. Cập nhật Memory Bank
Sau mỗi Step:
- Cập nhật activeContext.md.
- Cập nhật progress.md.
- Cập nhật systemPatterns.md nếu kiến trúc thay đổi.
- Cập nhật techContext.md nếu công nghệ thay đổi.
- Ghi lại file đã tạo và sửa.
- Ghi rõ những gì đã kiểm tra và chưa kiểm tra.
- Ghi lại lỗi còn tồn tại.

## 5. Tiết kiệm Token
- Không sao chép toàn bộ mã nguồn vào Memory Bank.
- Không lặp lại thông tin đã có.
- Chỉ đọc file liên quan đến nhiệm vụ.
- Viết báo cáo ngắn gọn nhưng đủ thông tin.
- Không tự tạo tài liệu không cần thiết.

## 6. Kết thúc Task
Bắt buộc:
1. Kiểm tra syntax và import/export.
2. Tổng hợp file đã thay đổi.
3. Cập nhật Memory Bank.
4. Ghi rõ trạng thái hoàn thành.
5. Ghi bước tiếp theo.
6. Dừng lại chờ người dùng xác nhận.
